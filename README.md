## ⚡ Executive Summary

Software Engineer with 2+ years of production experience architecting high-throughput distributed systems, polyglot microservices, and resilient cloud backends.

- **High-Throughput Scale:** Architected and deployed production backends supporting 10,000+ concurrent users with 99.9% uptime and sub-15ms telemetry latency.
- **Open Source Author:** Creator and maintainer of **[@bts-soft/core](https://www.npmjs.com/package/@bts-soft/core)** — an enterprise-grade modular NestJS infrastructure framework on npm, providing distributed Redis caching, BullMQ notification queues, composite validation, and SQLi guardrails.
- **Distributed Consistency & Messaging:** Deep specialization in polyglot engines (Go + NestJS), asynchronous streaming division (Apache Kafka, RabbitMQ DLX, NATS JetStream), and distributed consistency patterns (Saga Orchestration, Transactional Outbox, Polyglot Persistence).
- **Education:** B.Sc. in Computer Science & Artificial Intelligence, Damietta University (Class of 2025).
- **Target Roles:** Open to Remote & Hybrid Global Software Engineering roles.

### [@bts-soft/core — Enterprise NestJS Infrastructure Ecosystem](https://www.npmjs.com/package/@bts-soft/core)

_Production-Grade Modular Infrastructure Meta-Framework on NPM_

- **Ecosystem:** Consolidates 6 versioned packages: `@bts-soft/cache` (15 domain Redis services), `@bts-soft/validation` (AST SQLi guards & throttlers), `@bts-soft/notifications` (BullMQ multi-channel), `@bts-soft/upload` (chunked uploads), and `@bts-soft/common`.
- **Protocol Agnostic:** Dual-protocol architecture running identically across Express REST and Apollo GraphQL Federation.
- **Install Command:** `npm install @bts-soft/core`
- `NestJS` &middot; `TypeScript` &middot; `Redis Facade` &middot; `BullMQ` &middot; `SQLi AST Guards` &middot; `NPM Registry`

### [NestJS 12 Enterprise Starter Template](https://github.com/Omar-Sa6ry/nest-starter)

_Production-Ready Backend Starter with Native ESM, Apollo GraphQL & CI/CD_

- **Core Engine:** Built on NestJS 12, Node.js 22+, Express 5, Apollo GraphQL, and TypeORM with PostgreSQL under native ECMAScript Modules (ESM).
- **Resilience & Storage:** Multi-tier Redis caching, session blacklisting, S3/MinIO chunked uploads, and BullMQ with DLQ diagnostics.
- **Realtime & Payments:** Clustered WebSockets (Socket.IO with Redis Adapter) and a unified multi-provider payment engine (Stripe, PayPal, Paymob, Fawry).
- **Quality & Automation:** Automated CI/CD pipeline (CodeQL SAST, Aqua Trivy container scanning) with **628+ unit & E2E tests (92.8% coverage)** and companion CLI generator `@bts-soft/create-starter`.
- `NestJS 12` &middot; `TypeScript` &middot; `Apollo GraphQL` &middot; `TypeORM` &middot; `PostgreSQL` &middot; `Redis` &middot; `BullMQ` &middot; `Vitest` &middot; `Docker`
